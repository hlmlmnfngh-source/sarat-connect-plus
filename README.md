# سرعات (Sarat)

منصة عربية للعمل الحر تربط العملاء بمقدّمي الخدمات المستقلين، وتتيح تصفّح الخدمات المنشورة وطرح المشاريع المخصصة والتواصل حول الطلبات.

## التقنيات

- **TanStack Start** و **TanStack Router** لبنية التطبيق والتنقّل.
- **React** و **TypeScript** لبناء الواجهات.
- **Supabase** للمصادقة وقاعدة بيانات PostgreSQL والوصول إلى البيانات.
- **TanStack Query** لجلب البيانات وتخزينها مؤقتًا.
- **Tailwind CSS** ومكوّنات واجهة مبنية على Radix UI.
- **Stripe** لمعالجة الدفع في مسارات الدفع الموجودة بالمشروع.
- **Bun** لإدارة الحزم وتشغيل أوامر التطوير والبناء.

## التشغيل محليًا

المتطلبات: Bun بإصدار حديث، وإمكانية الوصول إلى مشروع Supabase الذي تستخدمه.

1. استنسخ المستودع وانتقل إلى مجلده.
2. ثبّت الاعتماديات:

   ```bash
   bun install
   ```

3. انسخ ملف البيئة النموذجي:

   ```bash
   cp .env.example .env
   ```

4. عيّن قيم البيئة الصحيحة محليًا، ثم شغّل التطبيق:

   ```bash
   bun run dev
   ```

5. للتحقق من الكود والبناء:

   ```bash
   bun run lint
   bun run build
   ```

لا تضع قيمًا سرية في Git، ولا تشارك ملف `.env`.

## متغيرات البيئة

راجع [`.env.example`](.env.example) باعتباره قائمة المتغيرات التي يتوقعها المشروع:

| المتغير | الغرض |
| --- | --- |
| `VITE_SUPABASE_URL` | عنوان Supabase الذي تستخدمه الواجهة. |
| `VITE_SUPABASE_PROJECT_ID` | معرّف مشروع Supabase المستخدم في إعدادات الواجهة. |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | مفتاح Supabase القابل للنشر والمستخدم في المتصفح. |
| `SUPABASE_URL` | عنوان Supabase المستخدم في سياق الخادم. |
| `SUPABASE_PUBLISHABLE_KEY` | المفتاح القابل للنشر عند الحاجة إليه في سياق الخادم. |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح مرتفع الصلاحيات للخادم فقط؛ لا تضفه أبدًا إلى متغيرات `VITE_*` أو إلى كود المتصفح أو المستودع. |

استخدم قيم مشروعك الفعلية في ملف `.env`. القيم النموذجية في `.env.example` ليست بيانات اعتماد صالحة للاستخدام.

## هيكل المجلدات

- `src/routes/`: صفحات التطبيق ومسارات TanStack Router.
- `src/components/`: مكوّنات الواجهة، بما فيها مكوّنات الموقع.
- `src/hooks/`: React hooks المشتركة.
- `src/lib/`: وظائف مساعدة ومنطق التطبيق.
- `src/integrations/supabase/`: عميل Supabase والأنواع المولّدة.
- `public/`: الملفات العامة الثابتة مثل الصور وملفات محركات البحث.
- `supabase/`: ملفات إعداد قاعدة البيانات وعمليات Supabase. لا تعدّل migrations أو functions دون مراجعة مستقلة.
- `.github/workflows/`: مهام CI الخاصة بالبناء والفحوص.

ملف `src/routeTree.gen.ts` مولّد تلقائيًا بواسطة TanStack Router؛ لا تعدّله يدويًا. شغّل `bun run build` لتحديثه عند تغيير ملفات المسارات.

## الدفع والأمان باختصار

- يمر الدفع عبر تكامل Stripe الموجود في المشروع؛ لا تعتبر أي صفحة أو نص واجهة دليلًا بحد ذاته على نجاح عملية دفع.
- العمولة المعلنة حاليًا هي **20% من قيمة كل طلب مكتمل**، دون اشتراكات شهرية.
- يجب أن تبقى مفاتيح الخادم الحساسة، وبالأخص `SUPABASE_SERVICE_ROLE_KEY` وأسرار Stripe، في إعدادات البيئة الآمنة على الخادم فقط.
- تعتمد حماية البيانات أيضًا على إعدادات Supabase وRow Level Security (RLS) وسياسات الخادم. راجع السياسات الفعلية قبل النشر ولا تضع مفاتيح أو بيانات شخصية في السجلات أو المستودع.
- لا تغيّر ملفات `supabase/` أو منطق الدفع والمحفظة ضمن تغييرات تنظيف الواجهة دون مراجعة واختبارات منفصلة.
